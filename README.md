# WARDEN

Scroll-driven 3D site (three.js, GSAP, Lenis, Vite).

```
npm install
npm run dev      # http://127.0.0.1:5190
npm run build    # outputs dist/
```

Requires Node 20.19+ or 22.12+. Set `X_URL`, `CONTRACT` and `SUPPLY` in `main.js` before deploying.
